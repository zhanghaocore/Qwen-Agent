## 重点测试功能

1. **文本清洗**
   - 空文本处理
   - 空白字符标准化
   - 特殊字符移除
   - 技术术语保留
   - 标点符号保留
   - 元数据提取

2. **句子分割**
   - 基本句子分割
   - 中文句子分割
   - 列表项处理
   - 缩写处理
   - 短句子合并

3. **术语提取**
   - 已知术语识别
   - 复合术语识别
   - 新术语识别
   - 术语分类
   - 置信度评分

4. **文本规范化**
   - 数字规范化
   - 日期规范化
   - 时间规范化
   - 缩写展开
   - 文本大小写规范化

5. **完整预处理流程**
   - 端到端处理
   - 批量处理
   - 元数据整合
   - 格式转换（字典/JSON）

## 发现的问题与修复

1. 文本清洗器在处理某些特殊字符时存在不一致性，已通过改进正则表达式模式解决。
2. 句子分割器在处理中文句子和标点符号时有改进空间，已优化算法。
3. 术语提取器在识别复合术语时准确率不足，通过添加更多模式和优化匹配逻辑提高了准确率。

## 测试建议
