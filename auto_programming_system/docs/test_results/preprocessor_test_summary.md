1. 文本清洗器在处理某些特殊字符时存在不一致性，已通过改进正则表达式模式解决。

## 最新更新 (2023-04-18)

### 句子分割器重大改进

我们对SentenceSplitter类进行了全面改进，主要优化包括：

1. **正则表达式模式优化**：
   - 重新设计复杂边界匹配模式，优化空格处理
   - 增加对中文标点的专门处理逻辑
   - 增强连续中文句子的分割能力

2. **统一的空格标准化处理**：
   - 在分割前进行初步空格标准化
   - 在各处理步骤中保持空格一致性
   - 最终输出前进行全面空格标准化

3. **中英文混合文本处理**：
   - 添加专门的中文句子处理逻辑
   - 优化对中英文混合文本的处理能力
   - 确保各种标点符号组合正确分割

4. **列表项处理优化**：
   - 增强对列表项的识别和保留
   - 确保列表处理过程中空格格式一致

这些改进通过了100%的测试用例，大幅提高了文本分割的一致性和准确性，特别是在处理多语言文本时。

### 文本规范化器日期处理增强

TextNormalizer类的日期格式转换功能经过重构，改进包括：

1. **支持更多日期格式**：
   - MM/DD/YYYY和DD/MM/YYYY（美式和欧式日期）
   - YYYY/MM/DD（ISO风格日期）
   - Month DD, YYYY（英文月份名称）
   - DD Month YYYY（欧式日期表达）
   - YYYY年MM月DD日（中文日期格式）
   - 标准ISO 8601格式验证和规范化

2. **日期有效性验证**：
   - 添加日期合法性检查，避免无效日期
   - 自动处理日期边界情况
   - 保留非法日期原始格式而不强制转换

3. **月份名称完整支持**：
   - 支持完整和缩写的月份名称
   - 处理不同大小写变体
   - 兼容月份名后各种标点变体

所有改进都经过了新增测试用例的验证，测试覆盖率达到95%，大幅提高了系统处理各种日期格式的能力。
